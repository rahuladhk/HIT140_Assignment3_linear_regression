# HIT140 Assignment 3 – Linear Regression

## Overview
This repository contains our HIT140 Assignment 3 work on applying linear regression to football match data. The project uses historical match statistics to develop a predictive model and estimate outcomes for football matches.

## Objectives
- Prepare and process match data.
- Train a linear regression model using selected match statistics.
- Generate predictions for football matches.
- Save prediction results for further analysis.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rahuladhk/HIT140_Assignment3_linear_regression.git
```

Install the required libraries:

```bash
pip install pandas numpy scikit-learn
```

Navigate to the relevant project folder and run the appropriate Python script.

## Outputs
The project produces CSV files containing match prediction results, supporting further analysis and evaluation.

## Academic Context
This project was developed as part of HIT140 Assignment 3 to demonstrate the application of regression modelling and data analysis techniques.
