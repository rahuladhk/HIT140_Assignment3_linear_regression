# HIT140 Assignment 3 – Linear Regression

## Overview
This project explores **linear regression** using Python as part of HIT140 Assignment 3. It applies regression techniques to football match data to investigate relationships between selected match statistics and outcomes, and to generate predictions.

## Features
- Data preparation and preprocessing
- Linear regression model development
- Match outcome prediction
- Prediction results saved to CSV files

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/rahuladhk/HIT140_Assignment3_linear_regression.git
   ```

2. Navigate to the project folder:
   ```bash
   cd "Linear regression 2.1"
   ```

3. Install the required dependencies:
   ```bash
   pip install pandas numpy scikit-learn
   ```

4. Run the relevant Python script:
   ```bash
   python predict_all_matches.py
   ```

## Output
The project generates CSV files containing match predictions for further analysis and evaluation.

## Purpose
This assignment demonstrates the application of linear regression and data analysis techniques to football match prediction.
